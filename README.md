# CSAI · Cơ sở Trí tuệ nhân tạo

Bài giảng Cơ sở Trí tuệ nhân tạo bằng tiếng Việt cho người mới bắt đầu, bám theo [Stanford CS221 (Spring 2025)](https://stanford-cs221.github.io/spring2025/modules/).

**Đọc online:** https://padduwcs.github.io/CSAI/

| Chương | Bài |
|---|---|
| 1. Học máy | Hồi quy và phân loại tuyến tính · Đặc trưng phi tuyến, mạng nơ-ron, lan truyền ngược · Tổng quát hóa, k-means |
| 2. Tìm kiếm | Mô hình hóa, DFS/BFS, quy hoạch động · UCS, structured perceptron, A* |
| 3. Quyết định Markov | MDP và đánh giá chính sách · Value iteration, học tăng cường |
| 4. Trò chơi | Expectimax, minimax · Alpha-beta, TD learning, trò chơi đồng thời |

Mỗi thuật toán được giảng theo mạch: bài toán → ý tưởng → cơ chế → ví dụ tính tay → tính chất → so sánh, kèm mô phỏng chạy từng bước ngay trên trang.

Trang tĩnh, không cần build: mở `index.html` bằng trình duyệt là dùng được, kể cả offline (trừ font chữ).
